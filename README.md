# Singhal Traders

Multi-page product catalogue website for Singhal Traders, Jaipur, Rajasthan.

## Pages
- Home — / 
- Searchable product catalogue — /products
- Individual product pages — /products/[slug]
- Category directory — /categories
- Havells, USHA and atomberg showcase — /brands
- Business profile — /about
- Enquiry details — /contact

## Stack
- Next.js 15 App Router
- React 19 + TypeScript
- CSS and Lucide icons

## Run locally
```bash
npm install
npm run dev
```

## Before launch
1. Add the verified business WhatsApp number, phone number and email address.
2. Connect the contact form to the approved email or WhatsApp destination.
3. Replace illustrative product photography with client-approved product images.
4. Confirm actual product names, models, specifications, brands and stock.
5. Confirm business profile, address and any authorised brand/dealer claims.
6. Run `npm run build` and test all routes on mobile and desktop before production.

Product names, models and images currently serve as illustrative catalogue placeholders, not confirmed inventory. Prices are shared on request.
