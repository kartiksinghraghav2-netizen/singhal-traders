# Singhal Traders

Modern product-catalogue website for Singhal Traders, showcasing electronics and home appliances for retail and wholesale enquiries.

## Stack
- Next.js 15 (App Router)
- React 19 + TypeScript
- CSS
- Lucide icons

## Run locally
```bash
npm install
npm run dev
```

## Before launch
1. Add the verified business WhatsApp number in `app/page.tsx` (`waNumber`).
2. Replace illustrative product photography with the client's approved product images.
3. Confirm actual brands, model names, specifications, stock and pricing.
4. Add the business address, contact number and approved company profile.
5. Connect the repository to Vercel and add the production domain.

Product names and images currently serve as catalogue placeholders, not confirmed inventory.
